# Peek v1 需求

## 定位

Peek 是一个 macOS 菜单栏应用：看系统状态，清理磁盘，卸载 App，做少量维护。目标是比同类商业软件更轻、更好看。

**所有功能用 Swift 原生实现，不调用、不打包任何外部命令行工具。**

## 原则

- **界面极简。** 弹出面板只放设计稿里的内容，其余功能进独立窗口。
- **安全优先。** 不能确认安全的文件就跳过。删除前一律先预览，用户确认后才执行。
- **原创实现。** 功能、路径、规则只取公开事实。做法是先把要实现的行为写成规格（如 `docs/clean-rules.md`），再按规格用自己的结构实现，不照搬其他项目的代码。

## 运行环境与分发

| 项目 | 决定 |
|---|---|
| 沙盒 | 不开。要删别的 App 的缓存，沙盒做不到 |
| 分发 | 不走 Developer ID 签名和公证，不上 App Store。直接把 `.app` 给用户 |
| 签名 | 用一个固定的自签名证书签名（不用临时签名），保证升级后系统授权不丢 |
| 首次打开 | 用户在"系统设置 → 隐私与安全性"里点"仍要打开"。文档和首次启动页要写清步骤 |
| 完全磁盘访问 | **可选，不强制。** 没授权时功能自动降级，见"权限" |
| 管理员权限 | v1 不需要。整个 App 以普通用户身份运行 |
| 最低 macOS | 14 |
| Bundle ID | 正式版 `cc.yuntianyou.peek`，开发版（Debug）`cc.yuntianyou.peek.dev`。发布后不能再改，改了系统会当成另一个 App，用户设置和授权全部丢失 |
| 官网 | https://peek.yuntianyou.cc |
| 工程结构 | XcodeGen：工程由 `project.yml` 生成，`.xcodeproj` 不进版本库，避免 `project.pbxproj` 合并冲突 |
| 界面语言 | 英文、简体中文，跟随系统语言。文案统一放 String Catalog（`Localizable.xcstrings`），代码里不写死文案 |

## 功能

### F1 菜单栏

- 菜单栏显示图标和健康分，如 `◉ 81`。
- 点击弹出面板，再点或点外面收起。
- 右键菜单：打开 Peek 窗口、设置、退出。

### F2 弹出面板

内容和顺序以设计稿为准：

| 区块 | 内容 | 数据 |
|---|---|---|
| 头部 | 健康分圆环、等级（Good 等）、设置按钮 | F3 |
| 指标 | CPU、内存、磁盘三条，右侧百分比；磁盘显示"40% of 926 GB" | F3 |
| 网络 | 下行、上行速度 | F3 |
| 按钮 | Analyze、Uninstall、Clean，各打开对应窗口（无主按钮；Optimize 入口暂时去掉，PEEK-24） | — |
| 底部 | 累计清理量、卸载项数、优化项数；“Last cleaned 2h ago”不在面板，放在 Clean 窗口顶部 | F8 |

- 某个指标超过阈值时，只把那一行换成强调色（如设计稿里的内存 84%）。
- 面板打开时每秒刷新；关闭后停掉高频采样，只为菜单栏分数低频采样（如 30 秒一次）。

### F3 系统状态与健康分

采集项（全部用系统接口，不需要额外权限）：

- CPU：总占用、每核占用、负载
- 内存：已用、总量、内存压力、swap
- 磁盘：启动盘已用和总量
- 网络：默认网卡的上下行速度
- 磁盘读写速度、电池（电量、健康度、循环次数）、占用最高的进程：v1 采集，只在独立窗口里展示，不进面板

健康分 0–100，由 CPU 持续占用、内存压力、磁盘余量、运行时长等合成，公式另写规格。分段对应等级文字和颜色。

v1 不做：温度、风扇（Apple Silicon 上要用私有接口）、GPU、蓝牙电量。

### F4 Clean

流程：扫描 → 按分类预览（大小、条数，可展开看路径）→ 勾选 → 确认 → 执行 → 结果汇总。

v1 分类（不需要完全磁盘访问的部分）：

| 分类 | 内容 | 默认勾选 | 删除方式 |
|---|---|---|---|
| 用户缓存 | `~/Library/Caches` 下的缓存 | 是 | 直接删除 |
| 日志 | `~/Library/Logs` | 是 | 直接删除 |
| 窗口状态 | 超过 30 天的 `Saved Application State` | 是 | 直接删除 |
| 浏览器缓存 | Chrome、Edge、Firefox、Arc、Brave 等 | 是 | 直接删除 |
| 开发工具 | npm、pnpm、yarn、pip、uv、Go、Homebrew、CocoaPods、Gradle 缓存；Xcode DerivedData、DeviceSupport；不可用的模拟器 | 是 | 直接删除，或调用对应工具自己的清理命令 |
| 已卸载 App 残留 | `Application Support`、`Preferences`、`HTTPStorages` 等处、对应 App 已不存在的文件 | 是 | 移到废纸篓 |
| 项目构建产物 | `node_modules`、`target`、`.build`、`dist` 等；7 天内有改动的不列 | 否 | 直接删除 |
| 安装包 | "下载"里的 `.dmg`、`.pkg`、`.iso`、`.xip` | 否 | 移到废纸篓 |
| 废纸篓 | 清空废纸篓（通过 Finder，需要"自动化"授权） | 否 | 清空 |

授予完全磁盘访问后增加：Safari 缓存、沙盒 App 的缓存（`~/Library/Containers`）、废纸篓大小显示。

要求：

- 可回收空间在后台计算并缓存，面板显示上次结果；打开 Clean 窗口时重新扫描。
- 安全规则（受保护路径、白名单、App 正在运行时跳过、不跟随符号链接、硬链接不重复计算等）单独写成 `docs/clean-rules.md`，每条规则注明路径、条件、删除方式。
- 遇到没权限的目录静默跳过，在明细里标"无权限"，不弹错误。
- 每次执行写入历史（F8）。

### F5 Analyze

- 选择位置：主目录、`/Applications`、启动盘、任意文件夹。
- 按大小排序显示子项，可逐层进入；单独列出大文件、超过 90 天的旧下载。
- 没权限的目录标"无权限"，不算进总量。
- 选中项可在 Finder 中显示、移到废纸篓（要确认）。

### F6 Uninstall

- 列出 `/Applications` 和 `~/Applications` 里的 App：名称、图标、大小、最后使用时间，可搜索、排序。
- 选中后预览要删的文件：App 本体加 `~/Library` 里能对应上的残留（按 bundle id 和名称匹配）。个人数据默认不勾。
- App 正在运行时提示先退出。
- 全部移到废纸篓，不直接删除。
- 系统自带的 App 和 Peek 自身不可卸载。
- **待验证：** 删除 App 本体会受"App 管理"权限限制，App Store 安装的 App 还需要管理员密码。开发时实测，必要时改为交给 Finder 删除。
- v1 不处理 `/Library` 下的系统级残留（LaunchDaemons、PrivilegedHelperTools 等，需要管理员权限）。

### F7 Optimize

只做不需要管理员权限的几项，每项可单独开关：

- 重置 QuickLook 缩略图缓存
- 清理超过 30 天的窗口状态
- 列出指向已不存在程序的 `~/Library/LaunchAgents`（只报告，由用户决定是否删除）
- 其余项开发时按价值补充

执行后显示每项结果：已完成、无需处理、已跳过（附原因）。

### F8 历史

- 本地记录每次清理、卸载、维护：时间、类型、条数、释放空间、失败数。
- 面板底部显示距上次清理的时间。
- 设置里可查看最近记录。

### F9 设置

- 皮肤切换（F10）
- 清理白名单：添加或移除不想被清理的路径
- 项目构建产物的扫描目录
- 刷新间隔
- 完全磁盘访问：显示当前状态；未授权时一行说明加"打开系统设置"按钮
- 开机启动（待验证在自签名下是否可用）

### F10 皮肤

- 所有皮肤共用一套数据和布局，只替换视觉组件：圆环、进度条、按钮、分隔线、字体、背景、装饰。
- 皮肤接口先定好。v1 共 5 套皮肤，按顺序实现：

  | 皮肤 | 需求 |
  |---|---|
  | 原生玻璃（浅色、深色跟随系统） | PEEK-3 |
  | 纸墨 | PEEK-12 |
  | 复古硬件 | PEEK-13 |
  | 北欧木纹 | PEEK-14 |
  | HD-2D 像素森林 | PEEK-15 |

- 位图素材放 `Assets`，同一个皮肤的素材不要两个需求同时改。

## 权限

| 权限 | 怎么获得 | 不给时 |
|---|---|---|
| 文件夹授权（桌面、文稿、下载） | 首次访问时系统自动弹窗 | 对应目录跳过 |
| 自动化（控制 Finder） | 首次清空废纸篓时系统弹窗 | 不能清空废纸篓 |
| 完全磁盘访问 | 用户在系统设置里手动打开 | Safari、沙盒 App 数据、废纸篓大小不处理 |

## v1 不做

需要管理员权限的功能（系统缓存、DNS 刷新、系统级残留）、温度和风扇、删除 Intel 代码、Touch ID、自动更新、外接盘清理。

## 性能

- 面板关闭时 Peek 的 CPU 占用应接近 0。
- 扫描在后台进行，不阻塞界面，可取消。
