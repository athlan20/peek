# Network 端口监控窗口规格

点击主面板的 **NETWORK** 卡片后，打开独立的 **Network** 窗口，完整展示本机所有已统计的监听端口，并支持快速打开、复制地址与终止占用进程。

## 入口与窗口

- 在 `PanelDestination` 中增加 `.network`，标题为 `Network`（中文：`网络`）。
- 主面板 `NetworkPortsCard`：
  - 点击单条可打开的端口行（`PortRowPill`）仍直接用浏览器打开 `http://localhost:<port>`。
  - 点击卡片其他区域（标题、速率、空白处、底部图例或 `+N`）打开独立的 `.network` 窗口。
- 窗口打开期间自动定时刷新端口列表，并同步显示主面板的实时上下行网络速率；支持手动点击刷新。

## 数据采集与进程终止

- 复用原生 BSD `PortSampler`（不依赖 `lsof` / `kill` 等外部命令）：
  - 在原有 `ListeningPort` 上补充 `executablePath`（复用已有 `proc_pidpath` 缓存）与 `establishedCount`（同一 FD 遍历中顺手统计本地端口对应的 `TSI_S_ESTABLISHED` 连接数）。
  - 过滤规则与主面板保持一致（排除系统路径、忽略列表及 `49152+` 临时随机 IPC 端口）。
- 进程终止（`PortProcessTerminator`）：
  - 原生调用 Darwin `kill(pid, SIGTERM)` 优雅退出；禁止终止 `pid <= 1` 或当前 Peek 自身进程。
  - 点击「释放端口 / 结束进程」前必须弹出二次确认框；若同一 PID 同时监听多个端口，确认框中明确列出所有将被一起释放的端口。
  - 若 `SIGTERM` 失败（如权限不足 `EPERM`），给出明确错误提示；若进程未退出，提示结果并刷新列表。

## 视觉布局：等大瓷砖矩阵（方案二 · Port Patch Panel）

延续 `Analyze` 与 `Uninstall` 窗口的深/浅自适应 Bento 视觉语言，默认展示**单层等大瓷砖矩阵**，并支持右上角切换为**列表视图**：

1. **去套娃的单层等宽等高网格**：
   - 每个监听端口直接渲染为一块等宽等高（`102pt`）的圆角发光瓷砖，按窗口宽度自适应 3~6 列（默认 680pt 窗口下为 4 列），横平竖直、零残片、无外层嵌套边框。
   - 瓷砖沿用 5 种语义分类色（Web 青、AI 绿、DB 黄、Proxy 蓝、Other 灰），按分类优先级顺序排布，同分类色块自然连片。
2. **瓷砖内信息层次清晰**：
   - 顶行：左侧分类胶囊（`WEB` / `AI` / `DB` / `PRX` / `TCP`），右侧在有活跃连接时展示绿点连接数，或在对外暴露（`*` / 局域网 IP）时展示地球角标。
   - 中央：居中大号等宽端口号（`:7895`）+ 进程名（`mihomo`）。
   - 底行：监听地址（`127.0.0.1` / `*`）与 `PID`。
   - 单击选中端口，双击可打开的端口直接启动浏览器访问，支持右键菜单快捷操作。

## 工具栏与底部操作栏

- **顶部工具栏**：搜索框（匹配端口、进程名、PID、地址）、分类筛选胶囊（All / Web / AI / DB / Proxy / Other）、实时 `↓ / ↑` 速率、刷新按钮、方块/列表切换器（持久化到 `network.layout`）。
- **底部栏**：
  - 左侧：选中端口详情（进程名、PID、监听地址、活跃连接数及路径提示）。
  - 右侧操作：`打开网页`（仅 Web/AI/Proxy 可用）、`复制地址`（带短暂「已复制」状态反馈）、`结束进程`（破坏性操作，弹二次确认）。
