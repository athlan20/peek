# 外观主题与浅色模式（Light Mode）规格

Peek 支持 **跟随系统 / 浅色 / 深色** 三种外观模式，默认跟随 macOS 系统外观。

## 1. 外观设置

- **持久化键**：`UserDefaults` 中的 `app.appearance`，取值为 `system`（默认）、`light`、`dark`。读到缺失或无效值时回退 `system`。
- **热切换**：由 `AppearanceManager.shared` 驱动，切换后立即生效，无需重启；同时通过 `NSApp.appearance` 与根视图 `.preferredColorScheme(...)` 保证菜单栏弹出面板、独立窗口（分析、卸载、设置）以及弹窗/工具栏统一同步。
- **入口**：设置窗口“通用（GENERAL）”卡片中提供三段切换控件（`跟随系统 / 浅色 / 深色`；英文 `System / Light / Dark`）。

## 2. 浅色模式视觉风格（Porcelain Mist Bento）

### 2.1 画布与卡片层级
- **画布底色**（`panelBackground`）：冷雾灰蓝 `#F1F4F9`（深色 `#131822`），使纯白卡片自然浮起。
- **卡片底色**（`cardBackground`）：纯白 `#FFFFFF`（深色 `#181E2A`），浅色下附带极轻投影（`#0F172A @ 4.5%`，radius 3，y 1）。
- **Hover 详情浮层**（`overlayBackground`）：浅色为 `#FFFFFF @ 94%`，深色为 `#131824 @ 93%`。
- **文字层级**：浅色使用深岩灰阶 `#0F172A @ 94%`（主）、`#334155 @ 80%`（次）、`#475569 @ 65%`（辅），确保白底与浅柔彩底上的对比度满足 WCAG AA。

### 2.2 Bento 卡片光影
- **顶部环境微光**：浅色下采用高明度低透明渐变（常态 `11%`，Hover `18%`，告警 `13%–20%`），避免深色模式高透明度渐变在白底发脏。
- **边框**：浅色下采用语义色细边（常态 `34%`，Hover `58%`，告警 `55%–85%`）。
- **语义强调色**：浅色下压深明度以保证白底可读性（CPU `#0D9468`、MEM `#DC3545`、Alert `#DC2626`、Network `#2563EB`、Battery `#3F9118`、Thermal `#C27803`）。

### 2.3 Treemap 方案 A（柔彩浅底 + 深色文字）
- **主面板 CPU / MEM 迷你方块**：浅色下采用浅柔彩渐变底（薄荷绿系 / 玫瑰杏橘系）配深色文字（CPU `#064E3B`、MEM `#7F1D1D`）。
- **分析窗口 Treemap**：各分类采用低饱和柔彩浅底配深岩灰文字；Agent 品牌色在浅色下与纯白按 `0.20 : 0.80` 混合。
- **卸载窗口 Treemap**：保持“7 天内冷蓝 → 久未使用暖陶”冷暖梯度，浅色下采用柔和浅色底配深岩灰文字，与应用彩色图标自然融合。
- **公共 Treemap 交互态**：浅色下取消黑色文字投影；选中描边改为系统蓝 `#2563EB`（2pt）；“其他”合并块为 `#E1E7F0`；运行中角标配白底蓝三角。
