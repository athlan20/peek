# Panel

点击菜单栏图标弹出的面板。按设计稿实现面板内容见 PEEK-3。面板只放设计稿里的内容，其余功能进独立窗口。

头部下方一行系统信息（芯片 · 内存 · macOS · 运行时长），CPU/内存补充说明行的右侧是 60 秒趋势小图（PEEK-17）；网络行的趋势图独占第二层、宽度占满，画下载（实线）和上传（虚线）两条线，两条线共用同一个分母归一化（PEEK-23）。趋势数据来自 `SystemMonitor` 的 `SampleHistory`，只在面板打开时累积。

网络行下面是电池行（台式机没有电池就不显示，不画折线）和高占用进程前 3 名，空数组时整块不显示；进程按 CPU 降序，只在面板打开时采样（PEEK-18）。底部不再显示“上次清理”（已挪到 Clean 窗口顶部）和累计值（清理总量、卸载项数、优化项数）；`HistoryStore.totals` 的数据仍在记录，只是面板不画。


按钮行是 Analyze / Uninstall / Clean 三个次按钮，没有单独的主按钮，也没有 Optimize 入口（PEEK-24）。Optimize 窗口的代码和累计里的“优化项数”先保留。
